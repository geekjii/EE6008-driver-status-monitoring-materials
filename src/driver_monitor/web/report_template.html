逐帧监测数据 / Frame measurements

表格保留全部记录，可横向滚动。空白表示未检测、未开始或不可用；数字 0 表示已测得的零值。手机结果在两次推理之间保持，查看“新推理”和“结果距今”可区分缓存与新检测。

监测配置、版本与统计详情 / Configuration and summary


手机置信度是模型对一次检测的评分，不能视作整体准确率。PERCLOS曲线仅在有效覆盖达到配置要求时显示；校准和不可用区间保持为空。报告可离线打开，完整数据和事件保存在同目录CSV及JSONL文件中。
