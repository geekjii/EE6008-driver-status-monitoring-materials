# EE6008 驾驶员状态监测项目资料

本仓库保存 EE6008 项目当前阶段真正需要的课程文件、项目汇报、参考研究和课堂口述记录，并为后续 AI 或组员继续开发提供统一入口。

## 重要状态

当前仓库是**课程与项目资料包**，不是已经能够运行的软件工程。

- 当前没有完整源代码、训练数据、模型权重或可复现的实验结果。
- 课堂讨论方向是驾驶员状态监测，重点包括疲劳、闭眼、打哈欠、注意力不集中等现象。
- DriveEye 可以作为最初的工程参考，但不能原样作为可靠研究基线；其环境、依赖、模型版本、时间判断和评估方法都需要修正。
- Windows 迁移的推荐目标是：Windows 11 + WSL2 + Docker Desktop + NVIDIA GPU，而不是直接使用 Jetson 专用的 L4T 容器。

## 教师要求的简单理解

项目不必只局限于“已经睡着”。更实用的目标是判断驾驶员是否进入危险状态，例如持续闭眼、频繁打哈欠、注意力转移或长时间没有专心驾驶。

教师允许小组自行选择算法、语言和数据来源，也可以录制模拟视频。项目应通过短视频或摄像头输入完成检测，并比较不同方法在准确率、速度、光照和场景变化下的表现。

## 建议的开发阶段

1. 建立一个能够在 Windows/WSL2 上运行的最小视频检测程序。
2. 复现并修正一个简单基线，记录依赖、模型、数据划分和指标。
3. 增加眼睛、嘴部和时间窗口特征，例如 EAR、MAR、PERCLOS。
4. 加入分心行为和风险等级融合，而不是只输出一个二元标签。
5. 使用不同驾驶员、不同光照和不同视频进行独立测试。

## 不应提交到仓库的内容
