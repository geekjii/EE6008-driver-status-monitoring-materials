# 监测数据导出

## 使用方法

1. 和以前一样启动系统，点击“开始监测”或选择本地视频。
2. 系统从第一帧开始记录，包括约五秒的启动校准。
3. 在网页下方点击“导出本次监测 / Export this session”，保存截至点击时的数据快照并下载ZIP数据包。监测可以继续。
4. 点击“停止”或视频结束后，系统会自动另存完整结果。
5. 点击“查看关键指标折线图 / View key indicator charts”，查看六张带中文解释的主要指标曲线；点击“完整数据报告”查看全部曲线和表格。也可以直接双击 `关键指标折线图.html` 或 `监测报告.html`，不需要启动服务或联网。

## 独立保存位置

```text
outputs/监测导出/
  监测_日期_时间Z_随机编号/
    监测数据.csv
    事件记录.csv
    逐帧原始数据.jsonl
    会话信息.json
    导出_时间Z_随机编号/
      监测报告.html
      关键指标折线图.html
      监测数据.csv
      事件记录.csv
      逐帧原始数据.jsonl
      监测摘要.json
      字段说明.json
      监测导出.zip
```

`Z` 表示文件名使用UTC时间，避免跨电脑时区差异。每次监测和每次导出都有独立编号。运行中快照和停止后的完整报告不会覆盖彼此。

CSV可以用Excel、Numbers或其他表格软件打开；采用UTF-8 BOM编码，列名为中英双语。HTML报告可单独打开并查看全部记录；CSV下载链接需要把同目录CSV文件一起保留，也可以直接从ZIP中解压全部文件。

## 数据包含什么

- 每帧序号、输入时间、记录时刻、处理FPS；摄像头时间为本次运行的相对时间，视频时间为片段内时间。
- 校准阶段、有效性、剩余时间、样本数、校准轮次、睁眼/闭嘴基准及实际使用的EAR/MAR阈值。
- 人脸是否检测到、当前面部指标是否可用、EAR、MAR、闭眼/张嘴判断及各自持续时间。
- PERCLOS数值、有效覆盖时间、是否达到最小覆盖要求、窗口内哈欠次数。
- 头部俯仰、左右、侧倾角度和持续偏离时间。
- 手机是否已经推理、本帧是否新推理、检测结果、置信度、推理时间、结果距今时间、持续出现时间、推理耗时、检测框坐标及设备。
- NORMAL/WARNING/DANGER最终状态、原始状态及全部原因；校准期间单独标记CALIBRATING。
- 开始/结束、来源、实际配置、软件版本、错误信息和时间统计。

每一帧都保存，正常状态和没有报警的时间也会保留。不保存原始视频或人脸图像。

## 怎么看报告

新版“关键指标折线图”优先展示眼睛开合、嘴巴张开、闭眼时间占比、头部方向、手机检测和系统状态。比例显示为百分数，等级标为“正常、警告、危险”，虚线使用当次监测的实际阈值，并给出中文解释。图的背景颜色对应系统当时的状态；移动到曲线上可以查看具体数值。原始数值不修改。

每次导出自动生成这份简明图表并放入ZIP。系统重启后也可以在网页下方打开最近保存的结果。这次指定的旧导出额外补充了 `关键指标折线图.html` 和 `监测导出_含折线图.zip`，原CSV和原ZIP保留。此项更新按用户要求没有运行测试。

报告顶部显示记录帧数、输入观测时长、人脸缺失时长、手机新推理次数和各等级持续时间。下面有九组曲线：EAR、MAR、PERCLOS、头部姿态、手机检测、风险等级、各类持续时间、处理帧率和手机推理耗时。

可以输入曲线起止时间，定位某个阶段；移动到曲线上会显示邻近时间的原始记录。表格支持按状态筛选、查找原因和分页，全部42列可以横向滚动查看。长曲线会保留分段极值及空白间断以控制绘图大小；表格、CSV和JSONL始终保留全部帧。

空白/null表示尚未开始、未测到或数据不可用，不能当成0。已测得的0会保留。例如：手机检测尚未开始时留空；做过检测且没有手机时记录0/false。手机两次推理之间沿用上次结果，因此应结合“本帧手机新推理”和“手机结果距今”判断。PERCLOS有效覆盖不足时曲线不显示，但原始数值和覆盖时间仍保存在表格中。

各状态持续时间按前一帧到下一帧的输入时间间隔累加，末帧没有后续观测，因此不额外估计尾部时长。多个报警原因可以同时出现，其持续时间不能相加当成总时长。

## 历史记录与验证范围

旧的 `outputs/events.jsonl` 已另存为“历史事件归档”中的CSV，原日志仍保留。旧日志只记录状态变化，不能恢复此前未记录的连续数据；完整逐帧曲线从使用新版进行的新一轮监测开始产生。

本轮完成69项自动化测试及离线报告图表、时间选择、状态筛选和表格检查。空白视频的原生模型全流程检查在首次初始化时超时，尚未完成；按用户要求，后续真人场景、长时间运行和全面性能验证先保留。正常Mac网页服务已恢复为默认配置，保持待机，自动设备选择报告为MPS；本轮没有开启摄像头，也未新增MPS推理性能结论。

人工构造的示例报告放在 `outputs/导出功能示例/` 并明确标记为测试数据。它用于查看导出样式和字段，不是真人实验结果。
